# Kalkulator (Python Tkinter)

Aplikasi kalkulator desktop bergaya modern 3D dengan tema pink pastel yang interaktif, dibangun menggunakan bahasa pemrograman Python dan pustaka Tkinter.

## Fitur Aplikasi

- **Operasi Matematika Dasar**: Mendukung Penjumlahan (+), Pengurangan (-), Perkalian (\*), dan Pembagian (/).
- **Desain Modern 3D & Estetik**: Memiliki efek tombol fisik timbul (3D raised effect) dan skema warna pink pastel yang manis.
- **Efek Interaktif**: Tombol akan memberikan respons visual (efek tekan ke dalam) saat diklik.
- **Penanganan Error**: Validasi otomatis untuk kesalahan format input dan pembagian dengan angka nol.

## Persyaratan Sistem

- Python 3.x sudah terinstal di komputer.
- Pustaka bawaan tkinter (sudah ada secara default di sebagian besar instalasi Python).

## Cara Menjalankan Program

1. Pastikan kamu berada di dalam folder proyek (tugas_Sahira_2311060125).
2. Buka terminal atau command prompt di direktori tersebut.
3. Jalankan perintah berikut:
   ```bash
   python kalkulator.py
   ```
